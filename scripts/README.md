# AI Code Review Script

This script uses OpenAI's o1-preview model (with fallback to gpt-4o) to perform comprehensive code reviews on C++ source files.

## Setup

1. Install dependencies:
```bash
cd scripts
npm install
```

2. Ensure your `.env` file contains an OpenAI API key:
```
OPEN_API_KEY=your-api-key-here
# or
OPENAI_API_KEY=your-api-key-here
```

## Usage

### Review all C++ files in src/
```bash
node ai-code-review.js
```

### Review specific files
```bash
node ai-code-review.js ../src/vector_store_v2.cpp ../src/document_loader.cpp
```

## Features

- **Comprehensive Analysis**: Reviews code for correctness, performance, maintainability, design, security, and compliance
- **o1-preview Model**: Uses OpenAI's latest reasoning model for in-depth analysis
- **Automatic Fallback**: Falls back to gpt-4o if o1-preview is unavailable
- **Markdown Output**: Saves reviews as formatted markdown files
- **Rate Limiting Protection**: Includes delays between requests
- **Batch Processing**: Can review multiple files in sequence

## Output

Reviews are saved in the `code-reviews/` directory with the format:
```
{filename}_review_{timestamp}.md
```

## Review Categories

Each review covers:

1. **Correctness**: Logic errors, undefined behavior, race conditions
2. **Performance**: Algorithm complexity, cache efficiency, SIMD opportunities
3. **Maintainability**: Code clarity, documentation, naming conventions
4. **Design**: Architecture, patterns, modularity
5. **Security**: Input validation, buffer safety, security practices
6. **Compliance**: C++ standards, platform compatibility

## Notes

- The o1-preview model has rate limits (50 queries/week as of 2024)
- Large files (>2000 lines) may exceed token limits
- Test files (starting with `test_`) are automatically skipped
- Reviews include ratings (1-10) for each category
