# GPT-5 Code Review Script

This script uses OpenAI's GPT-5 model via the new Responses API to perform comprehensive code reviews on C++ source files with advanced reasoning capabilities.

## Key Features

### GPT-5 Advantages
- **Enhanced Reasoning**: Uses chain-of-thought reasoning for deeper analysis
- **Configurable Depth**: Three review modes (quick, standard, deep)
- **Multi-turn Conversations**: Maintains context for follow-up analysis
- **Optimized for Code**: GPT-5 is specifically trained for code generation, bug fixing, and refactoring

### Review Configurations

| Config | Reasoning Effort | Verbosity | Use Case |
|--------|-----------------|-----------|----------|
| `quick` | minimal | low | Fast review for critical issues |
| `standard` | medium | medium | Comprehensive balanced review |
| `deep` | high | high | Detailed analysis with explanations |

## Setup

1. Install dependencies:
```bash
cd scripts
npm install openai dotenv
```

2. Ensure your `.env` file contains an OpenAI API key:
```
OPEN_API_KEY=your-api-key-here
# or
OPENAI_API_KEY=your-api-key-here
```

## Usage

### Basic Usage
```bash
# Review all C++ files with standard config
node ai-code-review-gpt5.js

# Review specific files
node ai-code-review-gpt5.js ../src/vector_store_v2.cpp ../src/document_loader.cpp
```

### Configuration Options
```bash
# Quick review (minimal reasoning, fast)
node ai-code-review-gpt5.js --config quick

# Deep analysis (high reasoning, detailed)
node ai-code-review-gpt5.js --config deep

# Standard review with follow-up analysis
node ai-code-review-gpt5.js --follow-up
```

### Combined Options
```bash
# Deep review with follow-up on specific files
node ai-code-review-gpt5.js --config deep --follow-up ../src/vector_store_v2.cpp
```

## Review Categories

Each review analyzes:

1. **Correctness** (1-10)
   - Logic errors, undefined behavior
   - Race conditions, memory safety
   - Specific issues with line numbers

2. **Performance** (1-10)
   - Algorithm complexity analysis
   - Cache efficiency, SIMD opportunities
   - Memory allocation patterns

3. **Maintainability** (1-10)
   - Code clarity and documentation
   - Naming conventions
   - Modularity assessment

4. **Design** (1-10)
   - Architecture and patterns
   - API design quality
   - Extensibility

5. **Security** (1-10)
   - Input validation
   - Buffer overflow risks
   - Security best practices

6. **Compliance** (1-10)
   - C++ standard compliance
   - Platform compatibility
   - Compiler-specific issues

## API Features Used

### Reasoning Effort
- **minimal**: Very fast, few reasoning tokens, best for simple checks
- **low**: Fast with basic reasoning
- **medium**: Balanced reasoning and response time
- **high**: Thorough reasoning for complex analysis

### Verbosity Control
- **low**: Concise responses, key issues only
- **medium**: Balanced explanations
- **high**: Detailed explanations with examples

### Multi-turn Conversations
The script can maintain context using `previous_response_id` for follow-up analysis on specific issues identified in the initial review.

## Performance Considerations

- **Token Usage**: GPT-5 uses reasoning tokens (not shown in output) plus output tokens
- **Rate Limits**: Higher than previous models but delays still included
- **File Size**: GPT-5 handles long context well (up to 200k tokens)
- **Fallback**: Automatically falls back to `gpt-5-mini` if rate limited

## Cost Optimization

- Use `--config quick` for routine reviews
- Reserve `--config deep` for critical code sections
- `gpt-5-mini` fallback provides cost-effective alternative
- Monitor reasoning token usage in output logs

## Tips for Best Results

1. **Start with `standard` config** and adjust based on needs
2. **Use `--follow-up`** for critical sections needing deeper analysis
3. **Review output tokens** to optimize cost
4. **Batch similar files** to maintain context
5. **Use `quick` config** for pre-commit hooks

## Troubleshooting

- **Rate Limits**: Script includes automatic delays and fallback to gpt-5-mini
- **Large Files**: Files >5000 lines may be slower but will process
- **API Errors**: Check API key and account status
- **No Output**: Verify file paths and permissions
